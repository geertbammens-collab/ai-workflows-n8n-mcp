Key Concepts

De vier kernbegrippen die je overal in Craft Agents tegenkomt, plus de voorbereide n8n workspace.

Vier kernbegrippen

Voordat we aan de slag gaan, is het nuttig om deze vier concepten te kennen.

📁

Workspaces

Een projectcontainer. Je kunt het vergelijken met een map op je bureaublad: alles wat bij een bepaald project hoort, leeft binnen die workspace.

📂

Working Directory

De werkmap op je computer waar je projectbestanden staan. Craft Agents kan die bestanden lezen, doorzoeken en aanpassen.

🔌

Sources

Externe verbindingen die Craft Agents extra mogelijkheden geven. Via API's en MCP kan de AI communiceren met diensten buiten je computer, zoals n8n.

🧩

Skills

Vooraf gedefinieerde instructies die de AI vertellen hoe een bepaalde taak moet worden aangepakt. Denk aan een receptenboek voor de AI.

De voorbereide n8n Workspace

Om de leercurve zo laag mogelijk te houden, werk je met een workspace die de trainer heeft klaargezet. Die workspace bevat alles wat je nodig hebt om Craft Agents en n8n naadloos samen te laten werken.

Drie MCP-servers

n8n Documentatie Server

Geeft de AI toegang tot de documentatie van alle n8n nodes, zodat die precies weet welke parameters een node verwacht en hoe die geconfigureerd moet worden.

Template Library Server

Maakt het mogelijk om te zoeken in de n8n template library, een verzameling van kant-en-klare voorbeeldworkflows.

n8n Cloud Server

Verbindt rechtstreeks met jouw n8n cloud account en stelt de AI in staat om workflows op te vragen, aan te maken, te wijzigen en te testen.

Ingebouwde Skills

Daarnaast bevat de workspace een reeks skills voor veelvoorkomende taken: het bouwen van een workflow op basis van een beschrijving, het troubleshooten van fouten, het toevoegen van error handling en meer.

Belangrijk: Zonder die voorbereide workspace zou je de AI elke keer opnieuw moeten vertellen wat n8n is, hoe nodes werken en hoe de API is opgebouwd. Met de workspace beschikt de AI over alle context die nodig is om je verzoeken snel en correct uit te voeren.
