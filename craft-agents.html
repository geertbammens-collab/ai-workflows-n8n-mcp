Craft Agents

Een desktop-applicatie waarmee iedereen kan werken met AI-agents - zonder programmeerervaring.

Wat is Craft Agents?

Een slimme assistent waarmee je een gesprek voert in natuurlijke taal.

Craft Agents is een desktop-applicatie die je in staat stelt om te werken met een AI-agent op een manier die toegankelijk is voor iedereen, niet alleen voor ontwikkelaars. Je kunt het zien als een slimme assistent waarmee je een gesprek voert in natuurlijke taal. Die assistent kan bestanden lezen, code doorzoeken, opdrachten uitvoeren en verbinding maken met externe tools via het Model Context Protocol (MCP).

Dat laatste is cruciaal voor onze training, want het MCP is de brug tussen Craft Agents en n8n. Je vindt Craft Agents op agents.craft.do.

Waarom Craft Agents?

Veel AI-werktools zijn gebouwd voor softwareontwikkelaars en gaan ervan uit dat je vertrouwd bent met terminals, code editors en technisch jargon. Craft Agents draait dat om. De interface is opgebouwd rond een chatvenster waarin je in gewone taal beschrijft wat je wilt bereiken. De AI interpreteert je verzoek, raadpleegt de beschikbare bronnen en voert de nodige stappen uit.

Krachtig onder de motorkap

Dat betekent niet dat de tool beperkt is. Onder de motorkap heeft Craft Agents toegang tot krachtige mogelijkheden: het kan bestanden lezen en schrijven, zoeken in documentatie, verbinding maken met externe API's en zelfs complete workflow-definities genereren. Maar al die complexiteit is verborgen achter een gespreksvriendelijke interface.

Installatie & eerste start

Download de applicatie

Ga naar agents.craft.do en download de versie voor je besturingssysteem.

Kies je LLM provider

Je wordt gevraagd met welke LLM provider je wilt werken. Je hebt de keuze tussen alle moderne Large Language Modellen.

Tip: De beste resultaten haal je uit Anthropic Claude. Maak een abonnement op claude.ai.

Authenticeer je account

Ga naar je LLM provider en genereer een code die je invoert in de authenticatie van Craft Agents.

Verken de workspace

Na authenticatie opent de app een workspace-venster. Je ziet een chatvenster en een zijbalk waarmee je je werkruimtes beheert.
